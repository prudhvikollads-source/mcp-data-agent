mcp-data-agent

A Model Context Protocol server for safe, read-only data exploration, plus an agent client that answers questions by discovering and calling its tools over stdio. This page is a static recording of a real run — no server, no scripts, no external assets.

list_tables describe_table run_query (SELECT only) SQLite, read-only offline demo

The recorded run

Command: python -m mcp_data_agent.demo "which plan has the most subscribers?"

Question: which plan has the most subscribers?
Tools discovered: list_tables, describe_table, run_query
Tool calls:
  1. list_tables()
     -> {"tables": [{"name": "customers", "row_count": 1200}, {"name": "invoices", "row_count": 4200}, {"name": "plans", "row_count": 6}, {"name": "subscriptions", "row_count": 1800}]}
  2. describe_table({"table": "plans"})
     -> columns: id INTEGER (pk), name TEXT, monthly_price_usd REAL, data_gb INTEGER
  3. describe_table({"table": "subscriptions"})
     -> columns: id INTEGER (pk), customer_id INTEGER, plan_id INTEGER, status TEXT, started_at TEXT, ended_at TEXT
  4. run_query({"sql": "SELECT p.name AS plan, COUNT(*) AS subscribers FROM subscriptions s JOIN plans p ON p.id = s.plan_id GROUP BY p.name ORDER BY subscribers DESC LIMIT 5"})
     -> rows: Pro 515, Unlimited 449, Plus 281, Starter 248, Enterprise 176
Final answer: The plan with the most subscribers is Pro with 515 subscriptions.

Why the query could not have hurt anything
